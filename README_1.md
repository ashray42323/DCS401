# DCS 401 – Week 5: NLP & Text Analytics

Two aspects demonstrated in Python (from class):

| Aspect | Tools | Script |
|--------|-------|--------|
| Tokenization & preprocessing | NLTK, WordCloud | `tokenization_demo.py` |
| Text summarization | sumy (LexRank, Luhn, LSA) | `summarization_demo.py` |

## Run
```bash
pip install nltk wordcloud sumy
python tokenization_demo.py
python summarization_demo.py
```
Plots are saved to the `figures/` folder.
